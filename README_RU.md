# Gravity Icons — порт iOS-твика Gravitational для Android (LSPosed)

LSPosed-модуль, воспроизводящий идею твика **Gravitational** (Havoc): иконки
рабочего стола подчиняются гравитации — падают к нижней кромке, складываются
в кучу, отскакивают друг от друга и прыгают, когда телефон трясёшь.

Реализация с нуля, без кода оригинального твика: физический движок
(интегрирование по кадрам vsync, столкновения кругов, затухание,
засыпание/пробуждение) + хуки на отрисовку иконок в Launcher3-форках.

## ⚠️ Не работает? (диагностика)

**Главный тест:** после включения модуля и перезапуска лаунчера иконки должны
**сразу упасть вниз** — ещё до всякой тряски. Разбираем по ситуациям:

**A. Иконки даже не падают** — хуки не работают. Смотри логи:
```
adb logcat -s GravityIcons XposedBridge
```
(или LSPosed Manager → Логи, поиск «GravityIcons»)

Что должно быть в логах при загрузке лаунчера:
- `hooked android.view.View.draw`
- `engine attached for <пакет лаунчера>`
- `icon registered: com.android.launcher3.BubbleTextView`

Что проверить, если строк нет или не хватает:
1. Модуль включён в LSPosed и отмечен scope? Перезагрузись после включения.
2. Scope указывает на **твой** лаунчер? Узнай пакет:
   `adb shell cmd shortcut get-default-launcher`
   Если он не из списка (Lawnchair, Nova и т.п.) — модуль его не трогает:
   добавь пакет в `LAUNCHER_PACKAGES` (GravityHook.java) и в
   `xposed_scope` (arrays.xml), пересобери.
3. Иконки не из Launcher3-мира? У Nova/Lawnchair свои классы — хук
   `View.draw` сработает, но `isIconClass()` их не опознает. Добавь имена
   их view-классов в `isIconClass()`.
4. В v1.0 был баг: хуки иконок молча не находились (findAndHookMethod ищет
   метод только в самом классе). Если у тебя v1.0 — обновись до v1.1.

**B. Иконки падают, но тряска не будит их** — проблема датчика/порога:
- Тряни **резче** или уменьши `SHAKE_THRESHOLD` (по умолчанию 1.8 м/с²).
- Датчик линейного ускорения может отсутствовать — тогда используется
  высокочастотная часть акселерометра, она менее чувствительна; уменьши
  порог до ~1.2.
- Увеличь `IMPULSE_GAIN_PX`, если иконки будятся, но едва дёргаются.

**C. Всё включено, но лаунчер убивается/глючит** — смотри лог на краши
(`adb logcat -b crash`), отключи модуль и напиши, на какой строке упало.

## Changelog

- **v1.1** — фикс главного бага: хук иконок больше не ищет `draw()` в

## Совместимость

- **Evolution X 11.x** (Android 16, QPR) — целевая прошивка.
  - Штатный **Evolution X Launcher** — пакет `com.android.launcher3`.
  - Внимание: свежие сборки Evo X 11 после мерджа QPR2 могут поставляться

Узнать свой лаунчер:
```
adb shell cmd shortcut get-default-launcher
```

## Требования

1. **Magisk** (Zygisk включён) или KernelSU + NeoZygisk.
2. **LSPosed** — официальный проект заморожен, для Android 16 нужен форк
   **JingMatrix** (v1.10.2-7189 и новее / v1.11 canary) или преемник **Vector**.
   Ставится как Magisk-модуль + manager.apk, затем перезагрузка.

## Сборка APK

1. Открой папку проекта в Android Studio (Hedgehog и новее).
2. Дождись синка Gradle (подтянется `de.robv.android.xposed:api:82`
   с api.xposed.info — это compileOnly, в APK он не попадает).
3. **Build → Build App Bundle(s)/APK(s) → Build APK(s)** → `app-debug.apk`.
   Либо из консоли: `gradle assembleDebug` (нужен Gradle 8.9+).

Если твоя Android Studio ругается на версию AGP — поменяй `8.5.2` в корневом
`build.gradle` на свою (например `8.7.x`), студия подскажет.

## Установка и активация

1. Установи `app-debug.apk` как обычное приложение.
2. Открой **LSPosed** → **Модули** → **Gravity Icons** → включи.
3. В **Scope** отметь лаунчер:
   - `com.android.launcher3` (Evo X Launcher), или
   - `com.google.android.apps.nexuslauncher` (Pixel Launcher).

   Scope уже предзаполнен метаданными модуля, обычно достаточно включить.
4. Принудительно останови лаунчер:
   `adb shell am force-stop <пакет_лаунчера>`
   (или Настройки → Приложения → лаунчер → Остановить, либо просто перезагрузись).
5. Готово: при запуске лаунчера иконки упадут вниз, при встряске — попрыгают.

## Вариант: установка как Magisk-модуль

Если хочешь systemless-установку — в архиве есть папка
`magisk-module-template`: положи собранный APK в
`system/app/GravityIcons/`, заархивируй содержимое папки в zip и прошей
в Magisk. Дальше всё равно нужно включить модуль и scope в LSPosed.
(Через Magisk APK попадает в /system/app; LSPosed видит его как обычное
приложение — так что оба способа эквивалентны, выбирай по вкусу.)

## Настройка физики

Все константы — в начале `GravityEngine.java`:

| Константа | Что делает | Значение |
|---|---|---|
| `GRAVITY_PX` | сила гравитации (px/с²) | 2400 |
| `DAMPING` | затухание (воздух), 1/с | 0.55 |
| `WALL_BOUNCE` | отскок от краёв сетки 0..1 | 0.35 |
| `WALL_FRICTION` | трение о стенку при ударе | 0.65 |
| `ICON_BOUNCE` | упругость столкновений иконок | 0.2 |
| `SLEEP_SPEED` | скорость «засыпания», px/с | 7 |
| `WAKE_ACCEL` | чувствительность к встряске/наклону, м/с² | 0.4 |
| `FILTER_ALPHA` | сглаживание акселерометра 0..1 (больше = резче) | 0.28 |
| `RADIUS_FACTOR` | радиус коллизии относительно иконки | 0.42 |
| `SHAKE_THRESHOLD` | порог встряски, м/с² (меньше = чувствительнее) | 1.8 |
| `IMPULSE_GAIN_PX` | сила толчка от встряски | 300 |

После правки — пересобери APK и переустанови (force-stop лаунчера достаточно).

## Как это работает (кратко)

- `GravityHook` ловит `Launcher.onCreate` (старт движка) и `draw(Canvas)`
  у `BubbleTextView` / `FolderIcon` — сдвигает холст на (x, y) из движка.
  Раскладка лаунчера не изменяется, только отрисовка.
- `GravityEngine` читает `TYPE_GRAVITY` (фолбэк — фильтрованный
  акселерометр) на отдельном потоке, переводит вектор в экранные координаты
  с учётом поворота дисплея и интегрирует по иконкам на vsync-кадрах.
- Иконки ограничены родительской сеткой страницы, сталкиваются кругами,
  засыпают в покое (Choreographer-цикл останавливается вообще — батарея
  не тратится) и просыпаются по изменению вектора гравитации.
- Список приложений и всплывающие меню исключены — физике подчиняются
  только иконки рабочих столов, дока и папки.

## Ограничения и известные особенности

- Виджеты не двигаются (они интерактивные, их смещение ломало бы тачи).
- Папка двигается целиком; содержимое открытой папки — нет.
- Если телефон лежит ровно на столе, иконки засыпают где лежали —
  разбудить их можно встряской или наклоном (как в оригинале).
- При смене ориентации/перевязке layout'а смещения могут сбрасываться —
  иконки просто упадут заново.
- Во время перетаскивания иконки её «тело» удаляется (иконка скрыта),
  после отпускания иконка падает с нового места — это фича.

## Отладка

```
adb logcat -s XposedBridge | grep GravityIcons
```
LSPosed Manager → Логи. Если хуки не находят классы — в логе будет
`class not found`; тогда проверь, что scope указывает на нужный пакет и что
лаунчер — Launcher3-форк (у Nova/Lawnchair имена классов другие, модуль
придётся адаптировать в `GravityHook.java`).
